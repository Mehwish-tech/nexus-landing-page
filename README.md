# Nexus Landing Page

A fully responsive SaaS product landing page built from scratch using HTML and CSS.

🔗 **Live demo:** https://mehwish-tech.github.io/nexus-landing-page/

---

## What this project is

Nexus is a concept landing page for a productivity SaaS platform. It was designed and built entirely by me to practise real-world frontend layout and design patterns used by modern tech companies.

---

## Features

- Responsive navigation bar with smooth layout
- Hero section with key stats and trust indicators
- Feature cards with image and description layout
- Testimonials section with real quote formatting
- Three-tier pricing section (Free, Pro, Enterprise)
- Full footer with multi-column link structure
- Clean, modern dark aesthetic throughout

---

## Built with

- HTML5
- CSS3 (Flexbox and Grid)
- No frameworks — pure HTML and CSS only

---

## What I learned

- How to structure a complete multi-section landing page
- CSS Grid and Flexbox for responsive layouts
- Designing pricing cards and feature grids from scratch
- Making a page feel professional through spacing and typography
